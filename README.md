# Guide Matcha Flavoured (fan-made)

Guide interactif et sans spoil pour le datapack **Matcha Flavoured** de Klei Wright, avec les mods RPG (Wizards, Paladins, Archers, Spell Engine, Spell Power, Skill Tree) et Waystones.

Guide de fan non officiel. Matcha Flavoured est sous licence CC BY-NC-SA 4.0 ; ce guide l'est aussi. Textures © leurs auteurs respectifs (Klei Wright, Mojang, auteurs des mods).

- Vidéo de présentation : https://www.youtube.com/watch?v=zyRH8W58fRI
- Wiki : https://matchaflavoured.wiki/

## Construire
```
python build.py
```
