# Changelog

All notable changes to the Matcha RPG Wiki. Versions follow [semantic versioning](https://semver.org/) (see README).

## [1.1.0] - 2026-10-09

### Added
- Enchantments tab: "who does what" memos with step-by-step diagrams for blessings (Benzene → Estus Ash → Stabilized Estus → Hell-Bound Book → blessing → anvil), the anvil, and the Spell Binding Table. Ingredient sources stay blurred.
- Spell Binding Table memo (also in the RPG magic tab): spell book creation, level and lapis cost per tier, and how many bookshelves unlock tier 2 / 3 / 4 spells (7 / 14 / 18), from Spell Engine 1.10.9's code.
- Blessing cards show their enchantments and what they do before the recipe is revealed.

### Fixed
- Warding enchantment showed as "2" instead of its name.
- Anvil hint said repairing costs no XP: it costs 1 level per ingot.

## [1.0.0] - 2026-10-04

Based on Minecraft 26.2, Matcha Flavoured 1.12.2, Wizards 3.1.3, Paladins 3.1.3, Archers 3.1.3, Spell Engine 1.10.9, Spell Power 1.6.2, Skill Tree RPGs 1.6.2, Waystones 26.2.0.12.

### Added
- Versioning: `VERSION` file, version shown in the header and footer, this changelog.
- English README describing the supported pack and mod versions.

### Changed
- Renamed the site from "Matcha Flavoured" to "Matcha RPG Wiki".

### Existing content
- Progression tree, recipes, cooking, equipment, enchantments, RPG magic, skill trees, waystones, trades, fishing & mobs, rules and names glossary.
